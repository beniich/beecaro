# Guide de Contribution

Merci de contribuer à BeeCarbonat ! 

## Règles de développement
1. **Branchement** : Créez une branche par fonctionnalité (`feature/ma-fonctionnalite`) ou correction (`fix/mon-bug`).
2. **Commits** : Utilisez les conventions Conventional Commits (`feat:`, `fix:`, `docs:`, etc.).
3. **Style de code** : Le projet utilise Prettier et ESLint. Assurez-vous que `npm run lint` passe sans erreur.
4. **Architecture** : Respectez le découpage modulaire du backend et du frontend. Ne placez pas de logique métier complexe directement dans les composants React.
5. **Tests** : Si applicable, incluez des tests unitaires pour votre code.
